# ФинПрогноз: прогноз денежных потоков и кассовых разрывов

Сервис для малого бизнеса: загружает банковскую выписку (CSV), строит прогноз остатка на 30 дней, находит дни возможного кассового разрыва и показывает сценарии «что если»: задержку оплаты крупным клиентом, падение выручки, внеплановый расход, отсрочку платежей поставщикам.

Стек: React + Vite + Tailwind (фронтенд), Node.js + Express (API), TypeScript-модель прогноза в `shared/`; Python + pandas/matplotlib для офлайн-EDA и графиков (`scripts/`, на сайте не выполняется).

## Локальный запуск

Сервис работает только локально (localhost), отдельный сервер не нужен. Нужен Node.js 24 (или 22.18+). Распакуйте проект в короткий путь, например `C:\projects\finprognoz`: на Windows длинные пути ломают сборку.

Режим разработки (горячая перезагрузка, без пароля):

```bash
npm ci
npm run dev
```

Production-сборка на локальном сервере (с паролем из `.env`):

```bash
cp .env.example .env        # задайте AUTH_USER и AUTH_PASSWORD
npm ci
npm run build
npm start
```

Сайт откроется на http://localhost:3000 (порт меняется через `PORT` в `.env`). Подробности и пересчёт офлайн-анализа на Python описаны в [SETUP.md](SETUP.md).

## Безопасность

- Все страницы и `/api/*` закрыты Basic-аутентификацией (`AUTH_USER` / `AUTH_PASSWORD`). Открыт только `/api/health`. В production без этих переменных сервер не стартует.
- Сервер не пишет в лог тела запросов и тексты ошибок: в логах остаются только тип ошибки и место в коде.
- Сырые выписки (`data/raw/`) не коммитятся и не раздаются как статика.

## Качество прогноза (бэктест)

Прогноз строится «из прошлого» на 6 датах среза (31.03, 30.04, 31.05, 30.06, 31.07, 31.08.2026) только по операциям до среза и сравнивается с фактическими остатками следующих 30 дней (факт за 01.04–30.09.2026). Охвачено 137 компаний из 150 (у остальных меньше 90 дней истории или нет 30 дней факта), всего 793 прогноза, из них 42 с фактическим кассовым разрывом (остаток ниже 0 ₽).

| Подход | MAE, млн ₽ | RMSE, млн ₽ |
|---|---|---|
| Аналоговые периоды (текущая модель, P50) | 1.22 | 3.41 |
| Синтетика sin/cos (прежняя версия) | 1.87 | 4.49 |
| Наивная: остаток не меняется | 1.23 | 3.38 |
| Линейный тренд за 90 дней | 1.37 | 3.76 |

Точечный прогноз остатка на уровне наивного, а главная ценность модели — оценка риска разрыва: при пороге вероятности 90% precision 0.68 при recall 0.76, при 50% — 0.28 / 0.88. У прежней модели precision около 0.15 при любом пороге.

Графики (PNG) лежат в `presentation_assets/metrics/`. Пересчитать:

```bash
node scripts/backtest.ts data/raw/train.csv data/raw/test.csv
python scripts/plot_backtest.py
```

## Структура

| Путь | Что внутри |
|---|---|
| `server.ts` | Express API: анализ выписки, прогноз, аутентификация |
| `src/App.tsx` | Интерфейс: загрузка, прогноз, симулятор «что если» |
| `data/` | Демо-выписка C052 (её отдаёт сервер); офлайн-результаты Python-скрипта: EDA и Ridge-прогнозы по 150 компаниям (сайт их не использует) |
| `data/raw/` | Сырые train/test кейса (локально, в git не входят) |
| `shared/cashflow.ts` | Модель прогноза (аналоговые периоды), рекомендации; общая для сервера и интерфейса |
| `scripts/` | Бэктест (`backtest.ts`) и графики метрик (`plot_backtest.py`), Python EDA и Ridge-прогнозы (`run_eda_and_benchmark.py`), слайды EDA (`export_presentation_charts.py`) |
| `reports/` | Метрики бэктеста (`backtest_metrics.json`) |
| `docs/` | Текст кейса (`case.pdf`) и описание датасета (`dataset_README.md`) |
