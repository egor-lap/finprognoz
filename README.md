# ФинПрогноз: прогноз денежных потоков и кассовых разрывов

Сервис для малого бизнеса: загружает банковскую выписку (CSV), строит прогноз остатка на 30 дней, находит дни возможного кассового разрыва и показывает сценарии «что если»: задержку оплаты крупным клиентом, падение выручки, внеплановый расход, отсрочку платежей поставщикам.

Стек: React + Vite + Tailwind (фронтенд), Express (API), Python + scikit-learn (EDA и обучение, `scripts/`).

## Быстрый старт (Docker)

```bash
cp .env.example .env        # задайте AUTH_USER и AUTH_PASSWORD
docker compose up --build
```

Откройте http://localhost:3000 и войдите с логином и паролем из `.env`. Порт на хосте меняется через `HOST_PORT`.

## Локальный запуск без Docker

Нужен Node.js 24 (или 22.18+). Распакуйте проект в короткий путь, например `C:\projects\finprognoz`: на Windows длинные пути ломают сборку.

Режим разработки (горячая перезагрузка, без пароля):

```bash
npm ci
npm run dev
```

Production-сборка на локальном сервере (с паролем из `.env`):

```bash
cp .env.example .env        # задайте AUTH_USER и AUTH_PASSWORD
npm ci
npm run build
npm start
```

Сайт откроется на http://localhost:3000 (порт меняется через `PORT` в `.env`). Подробности, переобучение моделей и Streamlit-прототип описаны в [SETUP.md](SETUP.md).

## Безопасность

- Все страницы и `/api/*` закрыты Basic-аутентификацией (`AUTH_USER` / `AUTH_PASSWORD`). Открыт только `/api/health`. В production без этих переменных сервер не стартует. Basic-аутентификация передаёт пароль в каждом запросе, поэтому снаружи сервис нужно публиковать только за HTTPS (reverse proxy).
- Сервер не пишет в лог тела запросов и тексты ошибок: в логах остаются только тип ошибки и место в коде.
- Сырые выписки (`data/raw/`) не коммитятся, не раздаются как статика и не попадают в образ.

## Структура

| Путь | Что внутри |
|---|---|
| `server.ts` | Express API: анализ выписки, прогноз, аутентификация |
| `src/App.tsx` | Интерфейс: загрузка, прогноз, симулятор «что если» |
| `data/` | Готовые артефакты (EDA, бенчмарк, прогнозы по 150 компаниям, демо-выписка C052) |
| `data/raw/` | Сырые train/test кейса (локально, в git не входят) |
| `scripts/` | Python: EDA и обучение (`run_eda_and_benchmark.py`), графики для презентации, Streamlit-прототип |
| `docs/` | Текст кейса и описание датасета |
