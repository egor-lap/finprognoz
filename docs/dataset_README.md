# Входные данные кейса «Прогноз денежных потоков для малого бизнеса»

Синтетические выписки по расчётным счетам **150 компаний малого бизнеса** за 2 года: с **01.10.2024 по 30.09.2026**. Всего около 222 тыс. операций.

Данные сгенерированы моделью, которая воспроизводит реальные процессы. Учтены:
- выручка с сезонностью и днями недели;
- эквайринг с зачислением на следующий рабочий день;
- оплаты клиентов по счетам с задержками;
- закупки у поставщиков;
- зарплата аванс плюс окончательный расчёт;
- единый налоговый платёж 28-го числа;
- кредиты, лизинг, аренда;
- поведение владельца, когда денег не хватает.

Все компании, контрагенты и ИНН вымышленные.

## Состав архива

| Файл | Что внутри |
|---|---|
| `statements/C001.csv … C150.csv` | Выписка по каждой компании отдельно |
| `all_operations.csv` | Все выписки одним файлом, те же строки |
| `companies.csv` | Справочник компаний: название, ИНН, форма (ООО/ИП), вид деятельности, первая и последняя дата операций |

## Формат файлов

- Кодировка **UTF-8 с BOM**, разделитель — **точка с запятой** `;`.
- Даты в формате `ГГГГ-ММ-ДД`, суммы с точкой: `12345.67`.
- **ИНН читайте как строку.** Вымышленные ИНН начинаются с `00`, и при чтении как числа ведущие нули потеряются.
- Excel открывает файлы корректно, но может обрезать нули в ИНН.

## Поля операции

| Поле | Описание |
|---|---|
| `company_id` | Идентификатор компании (`C001`…) |
| `operation_id` | Номер операции внутри выписки |
| `operation_date` | Дата операции (только рабочие дни по производственному календарю РФ) |
| `amount` | Сумма операции, всегда положительная |
| `direction` | Направление: `Поступление` или `Списание` |
| `counterparty_inn` | ИНН контрагента (10 цифр — организация, 12 — ИП/физлицо; может быть пустым) |
| `counterparty_name` | Наименование контрагента (обезличенное) |
| `payment_purpose` | Назначение платежа — свободный текст, как его заполнил плательщик |
| `balance_eod` | Остаток на счёте на конец дня. Одинаков для всех операций одного дня |

Остаток на начало первого дня = `balance_eod` первого дня − поступления + списания этого дня.

## Что важно знать о данных

- **Выписка по одному счёту в одном банке.** Часть компаний держит деньги и в других банках. Это видно по переводам «собственных средств» на счёт в другом банке и обратно.
- **Разные виды бизнеса:**

  | Вид бизнеса | Компаний |
  |---|---|
  | Общепит | 14 |
  | Продуктовая розница | 12 |
  | Одежда | 8 |
  | Маркетплейсы | 12 |
  | Строительство | 12 |
  | IT-услуги | 12 |
  | Опт | 12 |
  | Автосервис | 10 |
  | Салоны красоты | 10 |
  | Грузоперевозки | 10 |
  | Мебельное производство | 9 |
  | Сельское хозяйство | 7 |
  | Гостиницы | 7 |
  | Детские центры | 8 |
  | Клиники | 7 |

- **Разная история.** У большинства компаний полные 2 года, часть открылась в течение периода (в том числе за 2–3 месяца до конца), несколько закрыли счёт.
- **Налоговые режимы разные** (УСН 6%, УСН 15%, ОСНО, ЕСХН) и в данных явно не указаны.
- **Сезонность**: курорт летом, розница в декабре, урожай осенью, детские центры с сентября по май.
- **Граничные случаи**:
  - разовые крупные платежи и поступления;
  - задержки оплат от клиентов;
  - отрицательный остаток (овердрафт);
  - временное закрытие точки;
  - уход ключевого клиента.
- **Качество данных как в реальных выгрузках**:
  - бывают пропуски за несколько дней или недель (остаток после пропуска «скачет»);
  - пустые назначения платежа;
  - незаполненные ИНН;
  - единичные дубли строк;
  - возвраты ошибочных платежей.
- Одинаковые сущности могут описываться по-разному. Например, назначение налогового платежа: «Единый налоговый платеж», «ЕНП», «Единый налоговый платёж».

Данные синтетические, поэтому отдельные суммы и пропорции могут отличаться от реальной статистики конкретной отрасли.
